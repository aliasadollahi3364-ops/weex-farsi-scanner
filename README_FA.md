# اسکنر فارسی WEEX — نسخه اولیه

## امکانات فعلی
- پنل واکنش‌گرا و فارسی (RTL)
- دریافت کندل‌های عمومی فیوچرز USDT از API رسمی WEEX
- نمودار کندلی و ترسیم خطوط روند ساده
- شناسایی مقدماتی شکل‌های شبیه مثلث صعودی، نزولی و متقارن
- تنظیمات روشن/خاموش برای فیلترهای تحلیل
- مسیر آزمایشی ارسال پیام تلگرام با متغیرهای محیطی

## اجرا روی کامپیوتر یا سرور
Python 3.10 یا جدیدتر نصب باشد.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# Linux/macOS:
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

سپس مرورگر را باز کنید و به `http://127.0.0.1:8000` بروید.

## فعال‌کردن ارسال تلگرام
متغیرهای محیطی `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` را در محیط اجرای سرور تنظیم کنید و سرور را دوباره اجرا کنید. توکن را داخل کد یا فرانت‌اند قرار ندهید.

## محدودیت‌های نسخه اولیه
- این نسخه صرفاً نمونه قابل اجرا برای شروع است، نه سامانه آماده معامله یا سیگنال‌دهی زنده قابل اتکا.
- تشخیص الگوها مقدماتی است و باید با الگوریتم دقیق‌تر، داده تاریخی و آزمون گذشته‌نگر ارزیابی شود.
- در حال حاضر ارسال تلگرام فقط دکمه آزمایشی دارد؛ ارسال خودکار سیگنال در حلقه اسکن و جلوگیری از هشدار تکراری باید در مرحله بعد پیاده‌سازی شود.
- خطوط در تحلیل‌های مکرر ممکن است روی هم بمانند؛ برای نسخه نهایی باید مدیریت سری‌های نمودار و پاک‌سازی خطوط تکمیل شود.
- برای استفاده عمومی/شبانه‌روزی، سرور پایدار، احراز هویت پنل، محدودسازی درخواست و ثبت خطاها لازم است.
