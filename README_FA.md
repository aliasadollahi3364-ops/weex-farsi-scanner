# اسکنر فارسی WEEX — انتخاب ارزها

این نسخه یک پایه ساده برای انتخاب نمادها و تست اتصال تلگرام است. **این نسخه سیگنال واقعی تولید نمی‌کند و سفارش واقعی فیوچرز باز نمی‌کند.** قبل از اتصال معاملات واقعی باید منطق استراتژی و API صرافی جداگانه پیاده‌سازی و آزمایش شود.

## اجرا در Render
- Build Command: `pip install -r requirements.txt`
- Start Command: `uvicorn app:app --host 0.0.0.0 --port $PORT`
- برای تست تلگرام، در Environment Variables متغیرهای `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` را قرار دهید.
- کلید API صرافی را در چت یا داخل فایل کد قرار ندهید. مجوز برداشت وجه را فعال نکنید.

## انتخاب ارز
در صفحه اصلی نمادهای دلخواه را تیک بزنید و «ذخیره انتخاب‌ها» را بزنید. این نسخه فایل JSON را کنار برنامه ذخیره می‌کند؛ در Render ممکن است با استقرار مجدد یا راه‌اندازی مجدد از بین برود، مگر ذخیره‌سازی پایدار تنظیم شده باشد.
